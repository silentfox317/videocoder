# 🎬 VideoCoder

**AI-редактор видео в чате.** Описываешь словами что сделать — AI монтирует через MCP-video инструменты.

Основан на OpenCode. Добавлен MCP-video (81 инструмент), системные промпты переписаны под видеомонтаж.

## Что умеет

- Нарезка хайлайтов из длинного видео
- Склейка нескольких клипов
- Наложение субтитров/капшонов
- Аудио: извлечение, замена, наложение музыки
- Эффекты и цветокоррекция
- Стабилизация видео
- Транскрибация речи в текст
- Перепаковка для YouTube/TikTok/Instagram
- Стандартный shell для ffmpeg команд

## Запуск

```bash
./videocoder
```

Конфиг: `.videocoder.json` — там LLM провайдер и MCP сервер.
